# きらめき情報処理帳(情報処理検定2級 対策アプリ)

情報処理検定2級・ビジネス情報部門(用語・表計算・データベース)向けの、暗記カード+4択クイズアプリです。サーバーもログインも使わない静的な1枚のHTMLファイルなので、公開してもデータが外部に送信されることはありません。学習の進み具合(覚えたカード・スコア・にがて復習リスト)はすべて、使う人のブラウザ内(localStorage)だけに保存されます。

## ローカルで試す

`index.html` をダブルクリックするだけでそのまま動きます(外部ファイルを読み込まない単一HTMLのため、簡易サーバーは不要です)。

## 無料で公開する(このPCを起動していなくても使えるようにする)

GitHub Pages を使うと、GitHubアカウントさえあれば完全無料・PC不要でスマホからもいつでもアクセスできます。コマンド入力は一切不要です。

1. https://github.com/join でアカウントを作成する(無料)。すでに `eiken-app` 用に作成済みなら、この手順は不要です。
2. ログイン後、右上の「+」→「New repository」で新しいリポジトリを作成する。名前は何でもよい(例: `zensho2-app`)。Public/Privateどちらでも可(Publicの方が設定が簡単)。「Add a README file」はチェックしなくてよい。
3. 作成したリポジトリのページで「uploading an existing file」または「Add file」→「Upload files」をクリックする。
4. この `zensho2-app` フォルダの中の `index.html` をドラッグ&ドロップでアップロードする(`README.md` はアップロードしなくてOK)。`index.html` がリポジトリの一番上の階層に来るようにすること。
5. 画面下部の「Commit changes」をクリックしてアップロードを確定する。
6. リポジトリの「Settings」タブ→左メニューの「Pages」→「Build and deployment」の「Branch」を `main`(または`master`)・フォルダを `/(root)` に設定して「Save」。
7. 数分待つと、ページ上部に公開URL(`https://ユーザー名.github.io/リポジトリ名/`)が表示される。これをスマホのブラウザで開けば、このPCを起動していなくてもいつでも使える。

費用は完全に0円(GitHub Pagesは個人利用なら無料枠で十分)。

### アプリを更新したいとき

内容を修正した場合は、同じ手順で「Add file」→「Upload files」から `index.html` を再アップロードして「Commit changes」すれば、数分で公開サイトに反映されます。

## 中身の対応範囲について

用語(ハードウェア・ソフトウェア/通信ネットワーク・セキュリティ/表計算/データベース)、計算問題(2進数・稼働率・実効アクセス時間など)、表計算関数の実技寄りの問題を、情報処理検定2級ビジネス情報部門の一般的な出題パターンに基づいて作成しています。正式な過去問との一問一答での照合はしていないので、可能であれば教科書・過去問と見比べての調整をおすすめします。
